## SC Ore Scanner — install

A real-time Star Citizen mining overlay. **Single self-contained app — no Python, no setup.**

### Install (pick one)
- **Installer (recommended):** download `SC Ore Scanner_x.y.z_x64-setup.exe` (or the `.msi`) below and run it.
- **Portable:** download the `…-windows-portable.zip`, unzip, and run `SC Ore Scanner.exe` — nothing to install.

### First run
1. Launch it. The overlay appears top-right; the OCR engine warms up for ~15–20s.
2. Click **Set region**, then drag a box around the mining scanner's **RS** number and release.
3. Mine — detected ores show up with quantity and market price (aUEC/SCU, data from UEX Corp).

Star Citizen must run in **borderless/windowed** mode for the overlay to draw on top.

Logs: `%APPDATA%\com.scorescanner.app\logs\scanner.log`.
